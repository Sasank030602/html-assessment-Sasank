# HTML Tasks Repository

This repository contains a collection of advanced HTML-only tasks created for practicing and improving web development skills using pure HTML.

## 📚 Tasks Included

### Task 1: Multiple-Page Portfolio Website Structure
Created a structured multi-page portfolio website using only HTML.

### Task 2: Advanced Link Implementation & Navigation Patterns
Implemented different types of links, navigation menus, anchor links, and navigation patterns.

### Task 3: Complex Table Design with Nested Structures
Designed advanced HTML tables including merged cells, nested tables, and structured layouts.

### Task 4: Comprehensive Form Development with Validation
Developed detailed HTML forms using various input types, labels, fieldsets, and validation attributes.

### Task 5: Advanced Image Gallery with Multiple Formats
Built an image gallery using different image formats and responsive HTML image elements.

### Task 6: Semantic HTML Blog Layout with Rich Content
Created a semantic blog layout using HTML5 semantic tags and rich content formatting.

### Task 7: HTML Attributes & Metadata Showcase
Demonstrated the use of important HTML attributes, metadata, and head elements.

### Task 8: Complete Documentation Website with Accessibility
Developed an accessible documentation-style website following HTML accessibility best practices.
